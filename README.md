Sadiq Electric Store & Cable Merchant – Business Website

A responsive and professional business website developed for Sadiq Electric Store, a Karachi-based electrical engineering and panel manufacturing company established in 1996.

Tech Stack
HTML5

CSS3 (via custom styling)

Bootstrap 5.3

Font Awesome (for icons)

Responsive layout using Bootstrap's grid system and utility classes

Features
General

Fully mobile-optimized layout

SEO-ready structure and clean markup

Clear, accessible contact links (Phone, Email, WhatsApp)

Navigation

Sticky, responsive Bootstrap navbar

Smooth anchor linking across all sections (Home, About, Services, Products, Contact)

Visuals

Bootstrap Carousel for product banners

Multiple product/service cards with images and call-to-action buttons

Integrated Font Awesome icons for branding clarity

Sections Included

Top Bar: Contact links (phone, email, WhatsApp)

About Us: Company overview, core history, and leadership team

Services: Electrical engineering, installation, maintenance

Products: Custom electrical panels, cables, engineering support

Contact: Direct phone, email, WhatsApp integration

Footer: Copyright
